# WSL Demo — Примеры для презентации

Репозиторий содержит три демонстрационных скрипта для иллюстрации возможностей WSL (Windows Subsystem for Linux).

## 📋 Требования

- Windows 10 (версия 2004 или выше) или Windows 11
- WSL 2 установлен и настроен
- Python 3.x (для третьего примера)

## 🚀 Установка WSL

Если WSL еще не установлен, прописать в PowerShell от имени администратора:

```powershell
wsl --install
